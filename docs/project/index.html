Summary

asha is the Autonomous Simple Harness for Agents: the SimplyAutonomous.AI agent harness.

  • ./asha posts messages to named agent channels, watches them, and starts the daemon when needed.
  • The daemon runs agent images in colima containers, carries the channel between agents and the user, and brokers every model call.
  • Models are open-weight, served on the host by llama.cpp's llama-server.
  • Everything is local. The daemon binds only to 127.0.0.1; recurring cost is $0 (AGENTS.md §2, §7). See the system diagram.

Principles and repo rules

  • PRINCIPLES.md governs this repo. It is a one-line index loaded every session; each principle's text is a file in principles/, read when a task reaches it. It asks that nothing else enumerate the principles, so this page lists only how they apply here. §17–§21 date from 2026-09-27.
  • AGENTS.md is canonical for this repo; CLAUDE.md only points to it.

Precedence

AGENTS.md may be stricter than the principles where it names a reason. When a rule blocks correct work, stop and ask; never violate it silently.

How the principles apply here

  • §1: no deploy path. The gate is npm run check (lint → format check → typecheck → secret scan → unit → integration → build → demo selection → agents → eval → routing); nothing is done until it is green.
  • §2: origin is a private server; commit and push freely.
  • §3: the agent suite (npm run test:agents) and the eval (npm run eval) run real agents, both in the gate. npm run eval:routing measures the model's routing choices; its gate step, npm run eval:routing:gate, is the last step of the gate (since 2026-09-29).
  • §7: a paid model API, a hosted service, a second model backend or a second container runtime each needs a written justification first.
  • §11: every failure goes through src/daemon/log.ts (JsonLinesLogger).
  • §12: model licences, revisions, digests, and llama.cpp and colima behaviour are recorded with source and date in Models.
  • §17–§21: docs are .md sources rendered by npm run docs, linked from docs/index.md or their section index, under the documentation contract, guarded by tests/unit/docs.test.ts; one adversarial review per change; future work in Plans (docs/plans/index.md) via the planning workflow; shortcuts in the debt register (docs/plans/debt.md); done is checked by the checklists.
  • §22: there is no CDK infrastructure here; it applies only if some is added.

Rules specific to this repo (AGENTS.md §3)

AreaRule
PinsEvery model is pinned by Hugging Face commit sha plus a sha256 per file. A name or branch is never a pin.
LicencesVerified for the exact repo and revision served, and commercially permissive.
FormatsGGUF or safetensors only. Pickle formats are never downloaded.
Model cacheOnly the harness writes it: stage, verify every sha256, rename atomically. A digest mismatch is fatal and never retried.
ImagesRebuilt from the tree under test: each is tagged by its asha.source digest, so a changed tree is a new tag and a new build.
Model accessAgents never reach a model server directly; every call goes through /agent/v1/model/chat.
EnvironmentsNothing guesses an endpoint or environment. The one automatic behaviour, the CLI starting a daemon, is announced on stderr.
RecipesA recipe is the whole agent: one image, one model, and its bounds.
DeterminismOutput the gate asserts exactly decodes deterministically (chat.temperature: 0).
PlacementModels on the host, agents in colima, because colima's VM has no Metal.
