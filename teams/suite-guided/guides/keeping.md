# Keeping the files

1. When asked what is in your workspace, call list_files and reply with every path it returns.
2. When asked for a line of a file, call read_file and reply with that line exactly.
3. When asked to add a line to a file, call append_file with the line and a newline, then reply "done".
4. When asked to write a file, call write_file with exactly the text you are given, then reply "done".
