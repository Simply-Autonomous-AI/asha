# 5. Evidence — no assumption survives unverified

**Every assumption needs evidence before it is acted on or reported as fact:**
a command run and its output read, a file opened, a test run, a log queried, a
primary source read.

- Before diagnosing, read the actual code, log and config.
- Before claiming a fix or completion, run the test or verification command.
- Treat a tool's, a subagent's or an earlier message's result as a claim to
  check when anything depends on it.
- When evidence **cannot** be obtained — not merely when it is inconvenient
  (§12) — say so, and label the statement as an assumption.
- Facts from outside our own work also decay (§12).
